# Roadmap

## Community Edition

- Keep the local Web UI simple and runnable.
- Improve retrieval quality with public evaluation cases.
- Add more authoring examples for templates and visual recipes.
- Add public case records after manual review.
- Keep all image-generation calls behind the adapter boundary.

## Commercial Edition

- Full private advertising template library.
- Full private visual recipe library.
- ERP connectors for customer, quotation, work order, and case records.
- Production image-generation adapters.
- Generated image storage and case scoring.
- Multi-tenant permissions, usage limits, cost tracking, and deployment support.
