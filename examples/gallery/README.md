# Gallery

This directory documents public, reviewed examples and visual references.

The README preview images live in `docs/assets/gallery/` so GitHub can render them from the project front page. Source, license, and usage notes are tracked in [ATTRIBUTION.md](ATTRIBUTION.md).

Use `examples/briefs/community-briefs.json` and `examples/records/community-records.json` as text-first cases. Do not add customer images, private upstream reference images, or unlicensed poster artwork to the public repository.
