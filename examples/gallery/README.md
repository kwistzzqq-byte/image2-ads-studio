# Gallery

This directory documents 100 public, reviewed prompt cases and visual references.

The full image-to-prompt gallery is available in English at [cases.md](cases.md) and in Chinese at [cases.zh-CN.md](cases.zh-CN.md), with bilingual structured data in [cases.json](cases.json). Each case records preview attribution plus a library composite source made from matched templates and visual recipes. README preview images live in `docs/assets/gallery/` so GitHub can render them from the project front page. Source, license, and usage notes are tracked in [ATTRIBUTION.md](ATTRIBUTION.md).

中文入口：[cases.zh-CN.md](cases.zh-CN.md)。每个案例都包含中文 brief、中文 optimized prompt、英文 prompt、来源说明和风险提示。

Use `examples/briefs/community-briefs.json` and `examples/records/community-records.json` as text-first cases. Do not add customer images, private upstream reference images, or unlicensed poster artwork to the public repository.
